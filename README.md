AIGC 摄影训练营，到底教你什么
很多人以为 AIGC 摄影就是"输入一句话，等一张图"。真正做过的人知道，要出好片，背后是一整套方法。训练营教的，正是这套从创意到成片的方法。

第一，学会"用画面思考"

传统摄影靠取景，AIGC 摄影靠描述。训练营首先训练的是把脑中的画面，拆解成可表达的元素：主体是什么、环境是什么、光线从哪来、氛围是什么、镜头怎么给。这种"画面语言"的能力，是 AIGC 摄影的地基。

第二，掌握造景的逻辑

"造景"不是随便堆元素，而是有目的地构建一个可信、有美感的场景。训练营会教你如何安排主体与背景的关系、如何用光影塑造情绪、如何通过细节增强真实感。这些方法，既适用于 AI 生成，也反过来提升你的传统摄影审美。

第三，建立稳定的出片风格

零散出片容易风格摇摆。训练营强调建立个人视觉体系：固定的色彩倾向、构图习惯、题材偏好。有了体系，你的作品才有辨识度，客户才知道"找你能得到什么"。

第四，把 AIGC 融入真实业务

学技术不是目的，变现才是。训练营会带你思考：这项能力可以用在哪些场景？电商图、概念海报、写真、插画、短视频素材，每个方向的玩法都不同。找准方向，能力才能变成收入。

核心逻辑：AI 负责实现，你负责审美和判断

工具再强，也替代不了审美。训练营教的不是"如何让 AI 出图"，而是"如何让 AI 出好图"。
